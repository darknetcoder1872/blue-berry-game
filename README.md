# 🫐 Blue Berry - AAA Open-World Survival Game

## Project Overview

**Blue Berry** is a cinematic, AAA-quality open-world survival horror game built with Unity 3D. The player crashes on a mysterious island in Madagascar and must survive 6 days and 5 nights before finding the rare glowing "Blue Berry" fruit hidden deep within an ancient temple.

## Game Concept

### Story
After a plane crash near an unknown island region hidden from maps, the player awakens alone. The island contains dense forests, rivers, beaches, mountains, caves, abandoned labs, tribal ruins, underground bunkers, and zombie-infected areas.

### Main Objective
- **Survive for 6 Days and 5 Nights**
- **On Final Night**: Find the mysterious Blue Berry deep inside an ancient underground temple
- **Escape**: Survive zombies, mutated creatures, and deadly traps
- **Victory**: Reach the temple, defeat the Blue Guardian, collect the Blue Berry, and escape before sunrise

### Game Style
- ✨ Realistic graphics with URP pipeline
- 🎬 Cinematic atmosphere and emotional environment
- 🧟 Horror + survival gameplay mechanics
- 📱 Mobile + PC optimized
- 🎮 AAA-quality UI/UX

4. Load MainMenu scene
